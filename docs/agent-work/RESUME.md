## 2. ملخص ما تم تنفيذه وتثبيته

1. **وحدة التقويم الذاتي والاعتماد المدرسي وفق المؤشرات الرسمية لهيئة تقويم التعليم والتدريب (`R09` / `O009` — `etec-school-accreditation-2026-v2`):**
   - `shared/self-evaluation.ts`: المجالات الأربعة الرسمية بالأوزان النسبية المعتمدة (`الإدارة المدرسية 25%`، `التعليم والتعلم 35%`، `نواتج التعلم 25%`، `البيئة المدرسية 15%` = `100%`)، المعايير العشرة الرسمية (`1-1` حتى `4-2`)، وجميع المؤشرات الإجرائية المرمّزة (`1-1-1-1` حتى `4-2-1-3`: **48 مؤشرًا للمدارس الحكومية** و**51 مؤشرًا للمدارس الأهلية والعالمية** شاملة حوكمة وتراخيص التعليم الأهلي `1-4-1-1..3`) مع أدوات القياس المعتمدة (`تحليل الوثائق`، `الملاحظة`، `الاستبانات`، `المقابلات`، `الاختبارات الوطنية`) وترحيل تلقائي بلا فقد (`LEGACY_V1_INDICATOR_KEY_MAP`) لأي دورة سابقة.
   - `server/self-evaluation-db.ts` و`server/self-evaluation-router.ts`: دعم `schoolCategory`، تنظيف تلقائي للشواهد/التقارير المحذوفة ناعمًا من نفس النطاق مع رفض حازم لأي مرجع خارج النطاق، تتبع استخدام الشواهد في دورات التقويم داخل `domain.asset.usage` (`Used-in`)، وإتاحة إعادة إنشاء تقرير تنفيذ عند حذف التقرير السابق ناعمًا.
   - `client/src/pages/SelfEvaluationPage.tsx`: حساب حي وموزون فوري للمؤشرات (`liveSummary` + نطاقات `التهيئة / الانطلاق / التقدم / التميز`)، تجميع المؤشرات تحت المعايير العشرة، فلترة وبحث سريع، تنبيه قبل مغادرة تعديلات غير محفوظة، دعم الرابط المباشر `?cycleId=`، وتصدير JSON وطباعة التقرير الذاتي.
   - `shared/saudi-standards-packs.ts` و`server/standards-db.ts` و`SmartEvidenceMatrixPanel.tsx`: إضافة الحزمة الرسمية الثالثة `etec-school-accreditation-10` (المعايير العشرة الموزونة بـ 100%) مع عزل تغطية حزم المعلمين للملفات الشخصية وحزمة المدرسة للملفات المؤسسية.
2. **التدقيق المنطقي الشامل وإصلاح الحالات الحدية في الوحدات الجديدة:**
   - **المراجعات (`ReviewsHub.tsx` + `server/review-output-db.ts`):** منع تعيين منشئ النسخة كمراجع (`BR01`)، منع خطأ التكرار `ER_DUP_ENTRY` برسالة تعارض واضحة، عرض أسماء مقدم الطلب والمراجع، عرض لقطات ملفات الإنجاز (`portfolio`) في شاشة المراجعة، وتصفير حالات الخطأ عند التبديل بين المراجعات.
   - **تفاصيل الأعمال (`WorkDetail.tsx` + `server/domain-db.ts`):** قصر قائمة ربط الشواهد على نفس نطاق ملكية العمل، تقييد أزرار الكتابة والمراجعة بـ `viewerCanWrite`، تصفير الحالات عند الانتقال بين الأعمال، ومنع حذف الأعمال المعتمدة أو المؤرشفة أو أعمال الزملاء من قِبل عضو عادي.
   - **تصدير بيانات الحساب (`AccountHub.tsx` + `server/account-db.ts`) والمتجر (`Store.tsx` + `server/commerce-sandbox.ts`):** استبعاد إشعارات المراجعات المدرسية وسجل تبديل القوالب وشعارات Base64 من التصدير الشخصي، نقل حجز الحصة الذري إلى ما بعد نجاح الاستعلامات، واستبعاد الاستحقاقات المنتهية ومنع الشراء المكرر لمنتج مملوك فعليًا.
