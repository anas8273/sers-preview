# حزمة `arabic-ux` — المرحلة الأولى

## implemented

- عُرّبت صفحة 404 بالكامل داخل shell RTL، مع رسالة محايدة وزر واحد واضح «العودة للرئيسية» بلون teal، وتركيز أولي على الزر عند فتح الصفحة.
- استُبدلت حالة الصفحة الرئيسية الفارغة بلغة موجهة للمعلم تشرح الخطوة التالية، مع إجراء أساسي لإنشاء العمل وإجراء ثانوي لإضافة شاهد، من دون ذكر ربط واجهة أو قرار تنفيذ داخلي.
- ثُبّتت وجهات التنقل الأساسية الأربع (الرئيسية، أعمالي، الشواهد والأصول، المراجعات) مع «المزيد» لبقية الوجهات. أصبح `/reports` alias دلاليًا لعنصر «أعمالي» ليظهر كالمسار الخادمي الجديد، مع بقاء `/reports/legacy` للتقارير المحلية.
- أضيف `aria-current="page"` للعناصر النشطة، وتسميات landmarks، و`aria-expanded`/`aria-controls` للأدراج، وإدارة focus عند الفتح والإغلاق، وإغلاق بـ Escape واستعادة التركيز لزر الفتح في الشريط الجانبي والتنقل السفلي.
- أضيفت مهلة مشاركة عامة مقدارها 5 ثوانٍ. timeout وnetwork error وresponse error تعرض حالة عربية محايدة خلال المهلة، CTA «إعادة المحاولة»، ونصًا لا يكشف ملكية أو بيانات صاحب الرابط.
- وُسمت التقارير المحفوظة على الجهاز في `/reports` كمسار انتقالي، مع رابط `/reports/legacy` وعدم حذف أو نقل المسودات المحلية.
- أزيلت عناصر اختيار الملفات التي كانت تستدعي endpoint الرفع القديم من `ReportCenter` و`PortfolioBuilder`. بقيت إضافة الروابط اليدوية والمسودات المحلية، وتظهر رسالة صريحة لاستخدام مكتبة الشواهد للرفع والفحص.

## tested

- `pnpm exec vitest run server/arabic-ux.test.ts server/report-center-validation.test.ts` — اختبارات regression مصدرية مركزة لمسارات العربية والتنقل والمشاركة والرفع القديم وعقد مركز التقارير.
- `pnpm build` نجح بعد التعديل، بما في ذلك بناء Vite وتجميع الخادم. ظهر تحذير حجم chunks قائم من أداة البناء، وليس فشلًا.
- `pnpm check` شُغّل بعد التعديل، لكنه فشل فقط بأخطاء TypeScript موجودة خارج الملكية: `client/src/pages/WorkReportEditor.tsx:60` و`server/online-exam-admission.ts:167`.
- `pnpm exec prettier --check` على الملفات القائمة أبلغ أن نمطها غير منسق مسبقًا؛ لم أُعد تنسيقها حتى لا أغيّر ملكية أو diff الحزم الأخرى. يمر `git diff --check` دون whitespace errors.
- لم يُشغّل browser أو dev server أو suite كاملة، التزامًا بحدود الحزمة وعدم تشغيل browser/server بالتوازي.

## open

- لم يُحدّث `public/manus-routes.json` لأن ملف manifest ليس ضمن ملكية هذه الحزمة؛ يلزم دمج/تكامل لاحق من مالك route manifest مع إضافة `/reports/legacy` وأي مسارات المصدر المطلوبة.
- لا يثبت هذا المسار تطابق artifact المنشور مع SHA التطوير؛ provenance/build ID وsmoke matrix للنشر بوابة مستقلة.
- لم تُختبر رحلة OAuth أو API/MySQL أو قارئ شاشة فعلي؛ اختبار الوصول هنا source regression ويحتاج تحققًا مرئيًا لاحقًا عند توفر بيئة تشغيل.
- لا تزال hook توافقية `trpc.file.upload.useMutation()` موجودة في `ReportCenter` لأن اختبار الحزمة الحالي يثبت عقد المصدر، لكنها لا تُستدعى من أي زر أو handler بعد الإصلاح.

## القيود

- لم أعد بناء محرر التقرير أو renderer/schema ولم أغير auth/session/tenant/ownership/CAS أو WorkVersion.
- لم أضف اعتماديات أو migrations أو ملفات إنتاج أو نشر أو Git commit/push.
- إصلاح timeout يضع حدًا واجهيًا واضحًا ويعيد المحاولة مرة لكل نقرة، لكنه لا يغيّر عقد الخادم ولا يضمن أن endpoint الخارجي متاح.
- القياس responsive 390/1440 محفوظ عبر أصناف shell الحالية؛ لم يُنفّذ تصوير متصفح في هذه الحزمة.
