# Work report assets

- `ministry-logo.png` is the original color Ministry of Education logo already used in the Upgrade report assets. Transparent padding was cropped and the image resized without changing its proportions or colors. [Ministry visual identity reference](https://www.moe.gov.sa/ar/mediacenter/PhotoLibrary/Documents/moe_brand_guideline2025.pdf)
- Cairo, Tajawal and Noto Kufi Arabic come from [Google Fonts](https://github.com/google/fonts/tree/main/ofl) under the accompanying SIL Open Font Licenses. Cairo and Noto Kufi Arabic were converted from their upstream variable fonts to regular (400) and bold (700) instances. Tajawal is distributed as supplied upstream.
- The editor and PDF use the same font files. Word exports embed the selected Arabic family's regular and bold files so Arabic runs stay editable and can keep their font on other devices. Legacy Arial exports use the system font.
